# Chess Learning Game (Unity 3D)

## Описание проекта

Этот проект — обучающая программа для изучения шахматных основ с 3D-визуализацией. Приложение включает в себя теоретические материалы, практические задачи и интерактивную 3D-доску для отработки ходов. Оно разработано в среде Unity на языке C#.

## Возможности приложения

- Изучение основных правил шахмат.
- Теоретический материал по каждой фигуре и основным шахматным положениям (текст + изображения).
- Практические упражнения с возможностью двигать фигуры.
- Последовательное усложнение заданий.

## Технологии

- **Язык программирования**: C#
- **Среда разработки**: Unity
- **Физика движений**: Встроенные механизмы Unity
- **3D-модели**: Загруженные и настроенные шахматные фигуры

## Основные классы

- `MapGeneration` – генерирует доску и фигуры, считывает их начальные положения из файлов.
- `TouchController` – отслеживает взаимодействие пользователя с фигурами, контролирует передвижение.

## Логика работы приложения

1. В `MapGeneration` создаётся доска и размещаются фигуры по файлам-конфигурациям.
2. `TouchController` отслеживает клики по фигурам и вызывает методы `MapGeneration` для показа возможных ходов.
3. Проверяется корректность хода. Если он допустим, фигура перемещается.
4. В практических упражнениях проверяется достижение правильного результата.

## Алгоритмы шахматных фигур

- Ходы определяются относительно стартовой позиции фигуры.
- Проверяется наличие препятствий на пути (фигуры не могут перескакивать через другие, кроме коня).

## Ход работы

1. Изучение шахматных правил (в основе книга *«Учитесь шахматам» – Анатолий Карпов*).
2. Разработка концепции удобного интерфейса.
3. Изучение Unity и C# для реализации проекта.
4. Добавление текстовых файлов с позициями фигур.
5. Импорт 3D-моделей фигур в проект.
6. Разработка основных скриптов: генерация доски, перемещение фигур, логика ходов.
7. Создание визуальных элементов (правила, шахматные позиции, интерфейс).
8. Финальная доработка и тестирование.

## Скриншоты проекта

- **Главное меню** – выбор теории и практики.
- **Теоретический материал** – объяснение правил.
- **Практические упражнения** – интерактивная 3D-доска.
- **Примеры заданий** – решения шахматных задач.

## Запуск проекта

1. Установить Unity (рекомендуемая версия 2021.3 LTS и выше).
2. Клонировать репозиторий:
   ```bash
   git clone https://github.com/sofiiakasaeva/chess_on_unity.git
   ```
3. Открыть проект в Unity.
4. Запустить сцену `Menu.unity`.
